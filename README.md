# Okul Aile Birliği Seçimi

Sandık sayımı ve ekrana yansıtma sayfası. `index.html` tek dosyadır, GitHub Pages ile yayınlanır.

## Canlı bağlantı (iki bilgisayar)

`apps-script/Code.gs` dosyasındaki kod bir Google E-Tabloya Apps Script olarak eklenir ve Web uygulaması olarak dağıtılır.
Sitedeki Ayarlar bölümünde adım adım kurulum anlatılır. Oy giren bilgisayar ve projeksiyon bilgisayarı aynı E-Tabloya bağlanır.
